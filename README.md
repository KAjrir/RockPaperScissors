# Rock Paper Scissors

A game of Rock Paper Scissors against the computer, built as part of [The Odin Project](https://www.theodinproject.com/).

## Features
- Play against a random computer choice
- Result of every round and a running score for player and computer
- After 5 rounds the overall winner is announced

## Built with
HTML, CSS and JavaScript

## What I learned
- Breaking a problem down into small functions
- Updating the DOM based on game state
